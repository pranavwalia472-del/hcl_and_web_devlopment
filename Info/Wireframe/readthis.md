# Wireframes

This folder shows the wireframes of the main parts of the MediConnect UI. Some new components might be added later if necessary.

# Home

Home page wireframe

Navigation bar, an intro section with Book and Search buttons, three guide boxes explaining how the service works, and a footer.

# Doctors

Doctors page wireframe

Search bar, specialty filters and a grid of doctor cards, each with a Book Consultation button.

# Booking

Booking page wireframe

Step 1 of the 3-step booking form (patient details), with a progress indicator so users know where they are.

The follwing design was create mostly using MS.paint
